An end-to-end deep learning and digital signal processing system submitted for the MIREX 2026 AI-Generated Music Detection task. Given any music track, the system outputs a calibrated probability P(AI) between 0.0 and 1.0 determining whether the audio was generated by an AI music model (e.g., Suno, Udio, MiniMax, Mureka, YuE, ACE-Step) or composed and recorded by human artists.

## Architecture-1: MusicScope-CL

### 1. Dual-Branch Philosophy: Two Independent Failure Modes

Generative music models produce convincing local acoustic timbre, but often struggle to sustain natural, long-range human musical continuity. Humans leave natural acoustic space, expressive micro-timing variations, and deliberate harmonic tension.

MusicScope-CL combines two independent detection branches:

```
                         +----------------------------------------+
                         |           Raw Audio Input              |
                         |          (3 x 30s Chunks)              |
                         +-------------------+--------------------+
                                             |
                    +------------------------+------------------------+
                    |                                                 |
                    v                                                 v
        +-----------------------+                         +-----------------------+
        |  Branch A: Surface    |                         |  Branch B: Structure  |
        |  Log-Mel Spectrogram  |                         |  Musical Narrative    |
        |  MobileNetV3 Backbone |                         |  Domain-Specific DSP  |
        +-----------+-----------+                         +-----------+-----------+
                    |                                                 |
                    v                                                 v
        +-----------------------+                         +-----------------------+
        |   Surface Embedding   |                         |   Narrative Vector    |
        |       (576-dim)       |                         |       (128-dim)       |
        +-----------+-----------+                         +-----------+-----------+
                    |                                                 |
                    +------------------------+------------------------+
                                             |
                                             v
                               +---------------------------+
                               |     Fused Embedding       |
                               |         (704-dim)         |
                               +-------------+-------------+
                                             |
                                             v
                               +---------------------------+
                               |   SupCon Projection Head  |
                               |  Margin Clustering (128d) |
                               +-------------+-------------+
                                             |
                                             v
                               +---------------------------+
                               |   FusionMLP Classifier    |
                               | + Temperature Calibration |
                               +-------------+-------------+
                                             |
                                             v
                               +---------------------------+
                               |  P(AI-Generated) in [0,1] |
                               +---------------------------+
```

* Branch A (Surface Acoustics, 576-dim): Captures microscopic acoustic textures, vocoder smearing, phase anomalies, and high-frequency cutoff artifacts using a MobileNetV3-Small convolutional network.
* Branch B (Musical Narrative, 128-dim): Captures macroscopic structural continuity using classical digital signal processing:
  * Harmonic entropy and pitch stability.
  * Inter-Onset-Interval (IOI) variance and rhythmic groove.
  * Self-Similarity Matrix (SSM) recurrence rate (motif development vs. exact looping).
  * Spectral flatness, roll-off, and dynamic loudness arcs.

---

### 2. Four-Stage Training Pipeline

1. Stage 1 - Unsupervised SimCLR Pretraining:
   * Pretrained MobileNetV3 on 215,346 raw audio tracks using time-masking, frequency-masking, pitch-shifting, and additive noise augmentations.
   * Learns robust timbral representations without using noisy scraped labels.
   * Checkpoint: `simclr_epoch2.pt` (loss: 2.2113).

2. Stage 2 - Structural Feature Extraction:
   * Extracts 128-dimensional deterministic DSP vectors across the training set into Parquet format.
   * Artifact: `narrative_vectors.parquet`.

3. Stage 3b - Supervised Contrastive Fusion (SupCon):
   * Concatenates frozen 576-dim surface features and 128-dim structural features into a 704-dim vector.
   * Projects into a 128-dim normalized hypersphere using SupCon loss to maximize inter-class separation between Human and AI tracks.
   * Checkpoint: `supcon_best.pt` (loss: 3.7390).

4. Stage 3c - Calibrated Fusion Classifier:
   * Trains a lightweight FusionMLP (128 -> 256 -> 64 -> 1) on SupCon representations with label smoothing (alpha = 0.05).
   * Fits a post-hoc Temperature Scaler (T = 1.337) to guarantee well-calibrated confidence scores.
   * Checkpoint: `fusion_best.pt` (Validation AUROC: 0.9897).

---

### 3. Multiple Instance Learning (MIL) at Inference

AI-generated music often has realistic intros or stylized acoustic sections. During inference, `inference.py` automatically slices each track into 3 evenly spaced 30-second chunks across the song (intro, body, outro), scores each independently, and averages the results:

P_hat(AI) = (1 / N) * sum( sigmoid( f(x_i) / T ) )

## Quickstart

### 1. Environment Setup

```powershell
# Create Python 3.12 virtual environment
python -m venv .venv312
.\.venv312\Scripts\Activate.ps1

# Install PyTorch with CUDA acceleration and requirements
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu124
pip install -r Architecture-1/mirex/requirement.txt
```

---

### 2. Score a Single Audio File

Supports .mp3, .wav, .flac, and .ogg:

```powershell
python Architecture-1/mirex/inference.py `
  --input "path/to/song.mp3" `
  --simclr_ckpt "Architecture-1/mirex/checkpoints/simclr_epoch2.pt" `
  --supcon_ckpt "Architecture-1/mirex/checkpoints/supcon_best.pt" `
  --fusion_ckpt "Architecture-1/mirex/checkpoints/fusion_best.pt"
```

Example Output:
```text
[Scorer] Device: cuda
[Scorer] SupCon head loaded from checkpoints/supcon_best.pt

  song.mp3: P(AI-generated) = 0.8942
```

---

### 3. Batch Scoring (MIREX Submission Mode)

Score an entire folder of evaluation tracks and generate the official submission CSV:

```powershell
python Architecture-1/mirex/inference.py `
  --input_dir "path/to/evaluation_tracks" `
  --output_csv "mirex_submission_scores.csv" `
  --simclr_ckpt "Architecture-1/mirex/checkpoints/simclr_epoch2.pt" `
  --supcon_ckpt "Architecture-1/mirex/checkpoints/supcon_best.pt" `
  --fusion_ckpt "Architecture-1/mirex/checkpoints/fusion_best.pt"
```

---

### 4. Run Test Set Evaluation

Runs an automated evaluation across held-out Human and AI tracks and prints a scorecard:

```powershell
python Architecture-1/mirex/evaluate_test_set.py
```

## Training Reproduction Commands

To reproduce the four training stages from scratch:

```powershell
cd Architecture-1/mirex

# Stage 1: SimCLR Unsupervised Pretraining (Branch A)
python train_simclr.py --input_dir "D:\mirex\data\raw" --epochs 20 --num_workers 4

# Stage 2: Structural Feature Extraction (Branch B)
python track_a_narrative.py --input_dir "D:\mirex\data\raw" --output "D:\mirex\data\processed\narrative_vectors.parquet" --db "D:\mirex\data\processed\metadata.db" --workers 8

# Stage 3: Supervised Contrastive Fusion (SupCon)
python train_supcon.py --input_dir "D:\mirex\data\raw" --narrative "D:\mirex\data\processed\narrative_vectors.parquet" --simclr_ckpt "checkpoints/simclr_epoch2.pt" --epochs 30

# Stage 4: Fusion Classifier and Temperature Calibration
python fusion_model.py --narrative "D:\mirex\data\processed\narrative_vectors.parquet" --style_ckpt "checkpoints/simclr_epoch2.pt" --supcon_ckpt "checkpoints/supcon_best.pt"
```
